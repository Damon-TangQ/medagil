# Medagil AI平台

Medagil AI平台是一个综合性的AI解决方案平台，包含前端、后端、管理端和微信小程序四个主要部分。

## 项目结构

```
medagil-platform/
├── frontend/          # 前端应用 (Vue3 + TypeScript + Element Plus)
├── backend/           # 后端服务 (Node.js + Express + TypeScript)
├── admin/             # 管理后台 (Vue3 + Admin模板)
└── miniprogram/       # 微信小程序
```

## 技术栈

### 前端
- Vue 3
- TypeScript
- Element Plus
- Vite

### 后端
- Node.js
- Express
- TypeScript
- MongoDB/PostgreSQL

### 管理端
- Vue 3
- TypeScript
- Element Plus Admin
- Vite

### 小程序
- 微信小程序原生框架

## 快速开始

### 前端

```bash
cd frontend
npm install
npm run dev
```

### 后端

```bash
cd backend
npm install
npm run dev
```

### 管理端

```bash
cd admin
npm install
npm run dev
```

### 小程序

1. 使用微信开发者工具打开 `miniprogram` 目录
2. 配置AppID
3. 编译运行
