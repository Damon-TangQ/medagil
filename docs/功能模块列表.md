# 医学科研写作AI智能体平台功能列表


文档类型： 功能规划    
创建日期： 2026年1月22日    
最后更新： 2026年1月22日 


## 概述
本文档旨在详细描述医学科研写作AI智能体平台的功能模块，包括AI智能体功能点与平台功能点，以及分阶段的具体功能点及其优先级判定。

## 目录
1. 功能分类
2. AI智能体功能点介绍
3. 平台功能点介绍
4. 分阶段具体功能点（附优先级判定说明）

## 一、功能分类
1. **AI智能体功能**：围绕医学科研写作核心场景打造，为用户提供专业、深度的写作辅助支持。
2. **平台功能**：为用户使用智能体、开展科研写作工作提供基础支撑，涵盖用户管理、项目协作、数据集成与生态扩展等维度。

| 功能分类 | 具体描述 |
| :--- | :--- |
| **AI智能体功能** | - **论著写作智能体**：覆盖临床论著、基础研究、综述、病例报道、会议摘要等全类型学术论文的写作支持。<br>- **基金申请智能体**：针对国家、省部级等各类基金申请场景，提供从指南解读到方案撰写的全流程辅助。<br>- **毕业课题智能体**：面向博士、硕士、本科不同学历阶段，为毕业课题设计与论文写作提供针对性指导，适配不同阶段的课题难度与写作要求。<br>- **科普写作智能体**：帮助医学专业人士将专业知识转化为公众易懂的科普内容，覆盖科普短文、科普视频脚本、健康科普手册等创作场景。<br>- **科研工具智能体**：提供翻译、润色、文献分析、选刊等高频通用工具，作为基础能力支撑其他智能体的使用。 |
| **平台功能** | - **用户系统**：搭建安全的账户体系，完善权限管理机制。<br>- **项目管理**：支持项目的创建、协作、版本管理与成果归档工作。<br>- **数据源对接**：集成PubMed等外部知识库，丰富平台的数据生态。<br>- **客户端扩展**：提供Web、桌面端、小程序等多终端使用体验。<br>- **生态建设**：支持用户自定义智能体、开放API接口、搭建社区交流渠道，打造开放型平台。 |

## 二、AI智能体功能点介绍

### 1、论著写作智能体
| 智能体名称 | 核心功能 | 详细解释 |
| :--- | :--- | :--- |
| **临床论著助手** | 生成IMRAD结构框架；辅助撰写引言、方法、讨论部分。 | 可根据用户输入的研究数据类型（如RCT、队列研究）自动搭建论文骨架，针对各部分写作要点给出内容建议，保障论文逻辑严谨且符合期刊规范。实际使用时，还能结合目标期刊的风格偏好调整框架细节。 |
| **基础论著助手** | 辅助撰写实验方法；对结果提供图表化建议；构建研究故事线。 | 聚焦基础医学研究场景，帮助用户清晰描述复杂实验步骤，优化数据呈现形式，同时梳理从科学问题到研究结论的完整叙事逻辑，尤其适配分子生物学、细胞实验等常见基础研究类型。 |
| **综述/范围综述助手** | 生成系统性文献检索策略；辅助筛选文献；结构化提取数据。 | 全程指导用户完成文献综述撰写，从制定检索式到将大量文献信息整理成结构化表格，有效提升文献调研效率。检索策略会适配PubMed、Embase等主流数据库的语法规则。 |
| **Meta分析/系统评价助手** | 辅助撰写统计方法；集成PRISMA声明；结果部分整合可视化元素。 | 为Meta分析提供方法学指导，可自动生成符合PRISMA标准的流程图和报告，帮助降低证据合成研究的入门难度，同时支持森林图、漏斗图等可视化图表的初步生成。 |
| **病例报道助手** | 遵循CARE指南生成结构；辅助描述临床过程；提供隐私脱敏建议。 | 引导用户按照国际标准格式完整呈现有教学价值的病例，重点提示伦理与患者隐私保护要求，比如自动标注需要脱敏的患者信息字段。 |
| **研究方案助手** | 辅助撰写临床试验或研究方案。 | 提供标准化方案模板，覆盖研究背景、设计、样本量计算、伦理考量等关键模块，保障方案的科学性与规范性，模板可适配药物临床试验、观察性研究等不同类型。 |
| **会议摘要助手** | 根据研究内容生成符合会议要求的摘要。 | 帮助用户精准提炼研究核心成果，适配不同学术会议的格式与字数限制，提升摘要被接收的概率，已适配中华医学会、ESC、AHA等主流医学会议的摘要规范。 |

### 2、基金申请智能体
| 基金助手名称 | 核心功能 | 详细解释 |
| :--- | :--- | :--- |
| **国自然青年基金助手** | 解析申报指南；生成立项依据；构建研究方案和技术路线。 | 深度解读青年基金评审要点，重点辅助用户突出科学问题的创新性与研究方案的可行性，结合近年青年基金中标案例的共性特征给出优化建议。 |
| **国自然面上基金助手** | 针对面上项目特点提供写作建议（如更强调研究基础）。 | 在青年基金助手的基础上，强化项目团队前期研究基础与预实验数据的展示策略，帮助用户体现研究的延续性和团队的研究实力。 |
| **省自然基金助手** | 适配省级基金申请书格式和要求。 | 结合各省基金侧重应用研究、凸显地方特色的倾向，调整申请书的侧重点与表述方式，比如针对地方高发疾病的研究方向给出针对性建议。 |
| **国自然重点/专项基金助手** | 解析重点/专项基金申报逻辑；辅助搭建大项目研究框架。 | 针对重点/专项基金“聚焦重大科学问题、强调多学科交叉”的特点，帮助用户梳理研究体系的整体逻辑，突出研究的战略价值与应用前景。 |

### 3、毕业课题智能体
| 智能体名称 | 核心功能 | 详细解释 |
| :--- | :--- | :--- |
| **博士课题助手** | 辅助选题论证；构建博士课题研究体系；指导大论文框架搭建。 | 适配博士课题“创新性、系统性、深度”的要求，帮助用户完成选题查新与论证，梳理博士阶段的研究脉络，确保论文框架符合学位授予单位的规范。 |
| **硕士课题助手** | 平衡创新性与可行性；辅助课题设计；指导小论文写作。 | 结合硕士培养周期短的特点，优先推荐“创新性适中、易落地”的课题方向，同时辅助将课题成果拆解为符合核心期刊要求的小论文。 |
| **本科课题助手** | 简化课题设计；辅助基础写作；适配本科毕业论文规范。 | 结合本科阶段的知识储备与研究能力，提供轻量化的课题设计方案，指导论文基础框架搭建与格式规范，降低写作门槛。 |

### 4、科普写作智能体
| 智能体名称 | 核心功能 | 详细解释 |
| :--- | :--- | :--- |
| **医学科普短文助手** | 转化专业知识为通俗表达；适配公众号/科普平台风格。 | 将临床指南、研究成果等专业内容转化为普通人易懂的短文，自动调整语言风格以适配微信公众号、知乎、小红书等不同平台的传播特点。 |
| **科普视频脚本助手** | 生成医学科普视频脚本；适配短视频/长视频节奏。 | 结合视频传播的视觉化、口语化特点，生成包含台词、镜头建议、知识点拆解的科普视频脚本，支持1分钟短视频到10分钟科普长视频的脚本创作。 |
| **健康科普手册助手** | 结构化生成科普手册内容；适配不同人群认知水平。 | 针对老年人、儿童、慢性病患者等不同人群，调整科普手册的语言难度与内容侧重点，生成包含图文排版建议的手册框架。 |

### 5、科研工具智能体
| 智能体名称 | 核心功能 | 详细解释 |
| :--- | :--- | :--- |
| **医学翻译助手** | 高精度中英互译；优化医学术语和长难句。 | 基于医学专业语料库开展翻译工作，保障专业术语准确，语句符合学术表达习惯，适用于摘要、标题等关键内容翻译，支持批量文档翻译。 |
| **文献分析助手** | 快速总结单篇/多篇文献核心内容。 | 用户上传PDF文档后，可自动提取研究目的、方法、结果、结论等核心要素，生成摘要或对比分析报告，助力快速完成文献回顾，支持最多50篇文献的批量分析。 |
| **智能选刊助手** | 根据论文主题、水平推荐匹配的SCI期刊列表。 | 综合考量期刊影响力、审稿周期、发表费用及范围匹配度，为用户提供个性化选刊建议，同时标注期刊拒稿率、接收周期等参考信息。 |
| **论文润色助手** | 提升语言地道性；进行语法和风格检查。 | 对英文论文开展深度语言抛光，消除中式英语表达，让文风更贴近母语学者水平，支持按目标期刊的风格偏好定制润色规则。 |
| **审稿意见回复助手** | 逐条分析审稿意见；辅助生成回应信。 | 帮助用户分类整理审稿人意见，针对补实验、修改、解释等不同情况，起草礼貌、严谨的回复函，同时给出修改建议的优先级。 |
| **催稿信/伦理声明/致谢等助手** | 生成标准化文书；适配期刊格式要求。 | 提供催稿信、伦理声明、致谢等论文配套文书的模板，根据不同期刊的格式要求自动调整内容与排版，减少琐碎的格式调整工作。 |

## 三、平台功能点介绍
| 功能模块 | 功能说明 |
| :--- | :--- |
| **用户系统** | 提供注册、登录、身份验证与角色权限管理（如普通用户、管理员、机构用户）。采用微服务架构保障系统高可用与数据安全，用户数据管理遵循医疗数据隐私保护规范。 |
| **项目管理** | 支持用户创建、编辑、保存和管理科研项目。每个项目可关联多个文档、智能体输出内容和历史版本，支持多人协作编辑，历史版本可一键回溯。 |
| **数据源对接** | 集成PubMed等外部数据源，实现平台内文献一键检索与导入，为各类智能体提供丰富的背景知识；后续可扩展集成Embase、CNKI等数据库。 |
| **客户端扩展** | - **Web端**：基于Next.js搭建的响应式应用，功能完整，适配电脑、平板等多设备使用。<br>- **桌面客户端**：基于Tauri框架开发，提供离线操作与原生性能体验，核心功能（如文档编辑、智能体辅助）支持离线使用。<br>- **小程序端**：覆盖微信、字节跳动、小红书等平台，即用即走，主打轻量化功能（如快速翻译、文献摘要）。 |
| **生态建设** | - **用户自定义智能体**：允许高级用户基于自身工作流创建个性化智能体，支持简单的规则配置和功能组合。<br>- **API开放**：提供接口供第三方系统集成平台智能体能力，适配医院、高校科研管理系统的集成需求。<br>- **创作者社区**：搭建用户交流平台，方便大家分享智能体使用经验与模板，平台会定期筛选优质模板进行官方推荐。 |

## 四、分阶段具体功能点
### 优先级判定说明
本部分优先级结合「用户核心需求度（高频场景）+ 开发落地成本 + 商业价值」三个维度判定：
- 高优先级：高频核心场景、开发成本低、能快速验证核心价值/提升用户留存；
- 中优先级：场景需求明确、开发成本适中、对用户体验有显著提升；
- 低优先级：长尾场景、开发成本高、需在平台生态成熟后落地。
