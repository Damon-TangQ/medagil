## 一、第一阶段（MVP）：详细功能列表
### 核心目标
输出可体验的核心功能版本，完成MVP完整版落地，聚焦“基础论著写作+论文润色”核心场景，解决医学科研工作者“写得规范、改得专业”的核心痛点，同时搭建稳定、易用的基础平台支撑。

#### 1. 基础论著助手

| :--- | :--- | :--- | :--- |

| 论文结构搭建 | 生成IMRAD+基础研究专属结构 | - 自动生成“引言→实验材料与方法→结果→讨论→结论”标准框架<br>- 每个章节下细分二级标题（如“实验材料”含“细胞株、试剂、仪器”子模块）<br>- 支持自定义增减章节，自动调整整体逻辑衔接<br>- 提供结构合规性检查（如提示“未添加实验对照组描述”） | 新手用户可直接基于生成的结构填充内容，无需担心框架遗漏；资深用户可自定义调整，工具保障逻辑连贯 |
| 实验方法撰写辅助 | 全流程智能化支持 | - 实验模板库：内置50+常用基础实验模板（如PCR、Western Blot、细胞增殖检测），可直接引用并修改参数<br>- 参数自动补全：输入实验名称后，自动提示关键参数（如PCR的“退火温度、循环次数”）<br>- 操作步骤优化：将口语化描述转化为学术规范表达（如“把细胞放进培养箱”→“将细胞接种至培养皿后，置于37℃、5% CO₂恒温培养箱中孵育”）<br>- 试剂/仪器标注规范：自动提示“需注明试剂厂家、货号、批号”“仪器型号与生产厂家” | 用户撰写Western Blot实验方法时，直接调用模板，修改样本用量、电泳电压等参数，工具自动补全规范表述，避免遗漏关键信息 |
| 结果呈现辅助 | 数据可视化+规范描述 | - 图表类型推荐：根据数据类型（定量/定性、单因素/多因素）推荐适配图表（如定量数据推荐柱状图/折线图，组间对比推荐箱线图）<br>- 图表标注规范提示：自动提醒“图表标题需包含样本类型、检测指标、统计方法”“坐标轴需标注单位”“图例位置与格式统一”<br>- 结果描述模板：提供“数据统计描述+差异分析+生物学意义”三段式描述模板（如“XX组细胞存活率为（85.2±3.1）%，显著高于YY组的（62.5±4.2）%，差异具有统计学意义（P<0.05），提示XX因子可促进细胞存活”）<br>- 统计方法适配：支持t检验、单因素方差分析等基础统计方法的结果规范表述 | 用户上传细胞增殖数据后，工具推荐柱状图展示，提示标注“n=3，数据以均数±标准差表示”，并提供标准化结果描述文本，直接修改即可使用 |
| 研究故事线构建 | 逻辑串联+漏洞提示 | - 科学问题提炼：辅助用户明确“研究空白→本研究目标→拟解决的关键问题”，生成核心逻辑句<br>- 章节逻辑衔接：在章节过渡处提供衔接句模板（如“基于上述实验结果，我们进一步探究XX机制，具体方法如下”）<br>- 逻辑漏洞检测：自动识别“实验方法与研究目标不匹配”“结果无法支撑结论”“缺少阴性/阳性对照说明”等问题并提示优化方向<br>- 创新点突出：辅助提炼研究的核心创新点（如“首次发现XX因子在XX细胞中的调控作用”），并在讨论部分重点引导呈现 | 用户完成各章节撰写后，工具检测到“未说明实验重复次数”，提示补充；同时生成逻辑衔接句，让整篇论文叙事流畅，核心创新点清晰 |
| 术语与规范校验 | 专业准确性保障 | - 医学术语精准匹配：基于《医学主题词表（MeSH）》，自动修正不规范术语（如“癌细胞”→“肿瘤细胞”，“维他命”→“维生素”）<br>- 术语一致性检查：全文扫描并提示“同一术语表述不一致”（如前文“流式细胞术”，后文“FCM”未统一）<br>- 基础格式规范：自动调整字体、段落间距（适配学术论文标准），统一单位表述（如“mg/mL”而非“毫克/毫升”） | 用户撰写过程中，工具实时修正术语错误，确保全文术语统一、格式规范，减少后期排版工作量 |

#### 2. 论文润色助手
| 功能模块 | 核心功能 | 详细子功能 | 使用场景说明 |
| :--- | :--- | :--- | :--- |
| 分层润色体系 | 从基础语法到学术规范全覆盖 | - 基础语法修正：检测并修正拼写错误、语法错误、标点错误（如“affect/effect”混用、主谓不一致、逗号缺失）<br>- 表达流畅度优化：调整句式结构，消除中式英语表达（如“improve the level of”→“enhance”，“have a great influence on”→“exert a significant impact on”）<br>- 学术严谨性提升：将口语化表达转化为学术规范表述（如“we think”→“we hypothesize”，“very important”→“crucial”“pivotal”）<br>- 逻辑衔接强化：添加/优化连接词（如“furthermore”“nevertheless”“in contrast”），提升句子间逻辑连贯性 | 用户输入“Our experiment have a great influence on the research of cancer”，工具修正为“Our experiment exerts a significant impact on cancer research”，同时提示可替换为“Our study provides valuable insights into cancer research”以提升学术性 |
| 医学专属润色 | 适配科研场景专业需求 | - 医学术语润色：确保术语使用精准（如“myocardial infarction”而非“heart attack”，“hypertension”而非“high blood pressure”），并统一术语表述风格（如全文统一使用“mRNA”而非“messenger RNA”）<br>- 实验方法表述规范：优化实验操作描述的学术性（如“add the reagent”→“the reagent was added dropwise”，“we measured”→“the measurement was performed”）<br>- 统计结果表述规范：修正统计术语与格式（如“P < 0.05”而非“P<0.05”，“mean ± SD”而非“average ± standard deviation”） | 润色Western Blot实验描述时，工具将“we ran the gel at 120V for 1 hour”优化为“Electrophoresis was conducted at 120 V for 60 minutes on a 10% SDS-PAGE gel”，符合基础医学论文表述规范 |
| 目标适配润色 | 贴合期刊/场景需求 | - 期刊风格适配（基础版）：内置顶刊基础风格库（如《Nature》《Cell》《Journal of Immunology》），用户选择目标期刊后，自动调整句式长度、用词风格（如部分期刊偏好简洁短句，部分偏好详细长句）<br>- 字数控制：支持“压缩字数”“扩充字数”功能，按用户需求调整文本长度（如将摘要从350字压缩至250字，同时保留核心信息）<br>- 场景适配：区分“初稿润色”“投稿前润色”，初稿侧重流畅度，投稿前侧重严谨性与期刊适配性 | 用户计划向《Journal of Biological Chemistry》投稿，选择该期刊后，工具自动将长句拆分、简化用词，适配期刊风格；同时将摘要从320字压缩至280字（符合期刊要求） |
| 润色操作便捷性 | 提升使用效率 | - 润色痕迹追踪：采用“修订模式”，显示原文与修改建议，用户可一键接受/拒绝单个修改，或批量接受全部修改<br>- 多轮润色迭代：支持多次润色，工具记忆用户修改偏好（如用户拒绝“将method改为approach”，后续润色不再推荐该修改）<br>- 批量润色：支持上传Word/PDF文档，批量完成润色，生成带修订痕迹的文档供下载<br>- 重点标注：自动标注“高优先级修改”（如语法错误、术语错误）和“建议性修改”（如表达优化），用户可优先处理关键问题 | 用户上传10页的论文初稿，工具3分钟内完成批量润色，用红色标注语法错误（高优先级），蓝色标注表达优化建议（低优先级），用户批量接受高优先级修改，手动筛选低优先级修改，高效完成润色 |
| 附加辅助功能 | 延伸价值支撑 | - 查重预警（基础版）：检测文本中重复率较高的句子，提示“建议改写以降低重复率”，并提供3个改写版本参考<br>- 长难句解析：对超过30个单词的长句进行结构拆分，标注主谓宾、定语从句等，帮助用户理解修改逻辑<br>- 润色报告生成：润色完成后，生成详细报告，包含“修改总数、语法错误修正数、术语优化数、表达提升数”，以及“待用户确认的疑问点”（如“原文中‘XX试剂’未明确厂家，是否需要补充？”） | 用户润色后，收到报告显示“共修改128处，其中语法错误23处、术语优化35处、表达提升70处”，同时提示“摘要中‘显著差异’未标注统计量，建议补充P值”，帮助用户进一步完善论文 |

| 便捷操作功能 | 提升使用效率 | - 片段翻译：支持输入文本片段（≤500字），实时输出翻译结果<br>- 文档翻译（基础版）：支持上传Word/PDF文档（单次≤10页），批量翻译后生成带原文与译文对照的文档<br>- 术语自定义：支持用户添加“个人术语库”（如实验室专属试剂名称、自定义缩写），翻译时优先匹配用户自定义术语 | 用户实验室常用“XX试剂盒（自主研发）”，添加至个人术语库后，翻译时自动将英文“XX Kit”译为“XX试剂盒（自主研发）”，确保一致性 |

### （二）平台功能
#### 1. 用户系统
| 功能模块 | 核心功能 | 详细子功能 | 安全/合规说明 |
| :--- | :--- | :--- | :--- |
| 账户注册与登录 | 多方式便捷登录 | - 支持手机号+验证码、邮箱+密码、微信/企业微信第三方登录<br>- 密码强度校验：要求密码≥8位，包含大小写字母、数字、特殊符号，避免弱密码<br>- 登录保护：异常登录（异地、新设备）需验证手机号/邮箱，登录超时（30分钟无操作）自动退出 | 第三方登录仅获取用户昵称、头像等基础信息，不收集敏感数据，符合《个人信息保护法》要求 |

| 隐私与数据保护 | 全流程安全保障 | - 数据加密：用户上传文档、智能体输出内容采用AES-256加密存储，传输过程采用HTTPS协议<br>- 数据归属：用户所有数据（文档、项目、翻译/润色结果）归用户所有，平台仅用于功能实现，不泄露给第三方<br>- 数据删除：支持手动删除项目/文档，删除后30天内可恢复，超过30天永久删除；用户注销账户后，所有数据7天内永久删除<br>- 访问日志：记录用户登录、文档上传/下载、权限变更等操作，日志保留6个月，供用户查询与审计 | 严格遵循《医疗数据安全指南》《个人信息保护法》，确保医疗科研数据安全 |

| 版本管理与回溯 | 过程可追溯 | - 自动版本保存：每编辑10分钟或手动点击“保存”，自动生成新版本，保留最近10个版本<br>- 版本标注：支持为重要版本添加标签（如“初稿完成版”“润色后版本”“投稿前最终版”）<br>- 版本回溯：可查看任意历史版本，对比当前版本与历史版本的差异（红色标注删除内容，绿色标注新增内容），一键恢复至历史版本 | 用户误删论文中“实验结果”章节，通过版本回溯找到1小时前的版本，一键恢复，避免数据丢失 |

## 二、第二阶段（功能拓展）：核心功能要点
### 核心目标
拓展基金申请、文献分析等高频场景，提升用户留存，搭建更丰富的功能矩阵（待细化落地，仅列方向）

### （一）AI智能体功能要点
1. 论著写作智能体：新增临床论著助手、病例报道助手、会议摘要助手
2. 基金申请智能体：国自然青年基金助手 —— 解析申报指南、生成立项依据框架、技术路线图生成
3. 科研工具智能体：文献分析助手、智能选刊助手、审稿意见回复助手
4. 核心方向：聚焦“写作+基金+文献”闭环，解决从论文撰写到投稿、基金申报的核心需求

### （二）平台功能要点
1. 数据源对接：PubMed基础检索与文献导入
2. 客户端扩展：桌面客户端 —— 支持离线编辑、本地文档直接调用智能体
3. 项目管理：升级协作功能、版本管理扩展至20个历史版本
4. 核心方向：强化多终端适配与文献支撑，提升团队协作效率

## 三、第三阶段（生态完善）：方向规划要点
### 核心目标
覆盖全科研写作流程，构建开放生态，实现商业化变现（待细化落地，仅列方向）

### （一）AI智能体功能要点
1. 论著写作智能体：全系列覆盖（综述/范围综述助手、Meta分析助手等）
2. 基金申请智能体：全系列覆盖（国自然面上/重点基金、省自然基金等）
3. 毕业课题智能体：博士/硕士/本科课题助手（分基础/临床方向）
4. 科普写作智能体：科普短文助手、科普视频脚本助手
5. 科研工具智能体：全套工具（参考文献格式化、催稿信生成、论文降重等）

### （二）平台功能要点
1. 生态建设：用户自定义智能体、API开放（第三方集成接口）、创作者社区（经验分享+模板交流）
2. 客户端扩展：小程序端完整版（覆盖核心工具+文档同步）
3. 商业化功能：付费套餐配置（基础版/专业版/企业版）、订单管理、发票开具
4. 核心方向：从“功能工具”升级为“科研写作生态平台”，满足不同用户（学生、医生、科研机构）的差异化需求
