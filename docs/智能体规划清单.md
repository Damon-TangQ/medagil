# 智能体规划清单

**文档类型：** 功能规划  
**创建日期：** 2026年1月12日  
**最后更新：** 2026年1月18日 Pax
**适用范围：** Medagil AI 医学科研写作AI智能体平台

---

## 概述

本文档详细规划了医学科研写作AI智能体平台中各类智能体的功能定义、优先级和开发阶段安排。智能体按照医学科研写作的主要场景进行分类，覆盖从论著写作到基金申请、从毕业课题到科普写作的完整科研工作流程。

---

## 优先级说明

- **高 (High)**: MVP阶段必须实现的核心功能，用户价值最高
- **中 (Medium)**: 重要功能，在Phase 2实现，增强平台竞争力
- **低 (Low)**: 补充功能，在Phase 3实现，完善产品生态

## 开发阶段说明

- **MVP**: 最小可行产品阶段，重点验证核心价值
- **Phase 2**: 功能扩展阶段，覆盖主要科研场景
- **Phase 3**: 生态完善阶段，构建完整的科研写作生态
