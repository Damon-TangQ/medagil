# 小程序端技术实现方案（MVP）

**文档类型：** 端侧技术实现  
**适用范围：** Medagil 微信小程序端  
**关联文档：** [总览技术实现方案(MVP)](../技术实现方案(MVP).md) · [小程序端功能清单(MVP)](小程序端功能清单(MVP).md)

---

## 1. 技术栈（已确定）

| 类别 | 技术 | 用途 |
|------|------|------|
| 框架 | Taro + 微信小程序 | 多端统一开发，MVP 以微信为主。 |
| 语言 | TypeScript | 类型安全。 |
| 状态管理 | Mobx | 页面与全局状态。 |
| UI | Taro UI | 小程序通用组件（列表、表单、弹窗等）。 |
| 网络 | Taro.request | 调用自研后端 API；统一封装鉴权与错误处理。 |

**端能力**：微信登录、手机号授权、分享、微信支付均通过微信小程序 API + 后端接口配合完成。

---

## 2. 与功能清单的对应实现

以下按 [小程序端功能清单(MVP)](小程序端功能清单(MVP).md) 的 7 大模块，说明各模块在小程序侧的技术实现要点。

### 2.1 个人中心与设置

| 功能点 | 实现要点 |
|--------|----------|
| 个人资料（头像、邮箱、当前计划） | 用户信息接口展示；头像使用微信头像或上传接口。 |
| 升级计划、积分获取、个性化设置 | 与 Web 用户端逻辑一致；订阅页、积分活动、设置表单；数据来自同一后端。 |
| 创建技能、定时任务、外观设置、获取帮助 | 技能/定时任务 CRUD 页面；主题切换；反馈表单提交。 |
| 分享小程序 | `wx.shareAppMessage` / Taro 分享配置；分享卡片与路径参数。 |
| 微信授权登录、手机号码登录 | `wx.login` 取 code 交后端换 Token；手机号通过 button open-type 获取并交后端验证。 |

### 2.2 搜索

| 功能点 | 实现要点 |
|--------|----------|
| 列表、全文搜索，历史对话搜索 | 搜索输入框 + 防抖请求；结果列表页；历史对话为任务列表接口带关键词。 |

### 2.3 项目管理

| 功能点 | 实现要点 |
|--------|----------|
| 创建/查看/多级分类，项目编辑（新增、编辑、指令） | 项目列表与树形/层级展示；新建/编辑页与全局指令输入；与后端项目 API 一致。 |

### 2.4 成果库

| 功能点 | 实现要点 |
|--------|----------|
| 创建/查看/归档/收藏，列表与搜索（按名称/状态筛选） | 成果库列表与筛选；归档/收藏状态切换；与 Web 用户端共用后端接口。 |

### 2.5 任务对话

| 功能点 | 实现要点 |
|--------|----------|
| 文档支持 | Word、PDF、TXT、Markdown 上传（见功能清单）；小程序内选文件 `wx.chooseMessageFile` 或上传组件；后端做格式校验与存储。 |
| 新建任务（文本、附件、高级模式、语音） | 主输入框 + 附件入口；高级模式为多步表单；语音为录音 + 识别接口（后端或微信语音识别）。 |
| 任务执行（步骤展示、思考过程） | 流式数据展示；小程序可通过轮询或 WebSocket/SSE（若支持）与后端或 Dify 对接。 |
| 结果交互（内容展示、附件下载、分享、评分） | Markdown 渲染（可用小程序富文本或自定义）；下载与分享调小程序 API；评分为表单提交。 |

### 2.6 导航与组织

| 功能点 | 实现要点 |
|--------|----------|
| 侧边栏（搜索、库、项目、所有任务、界面切换） | 小程序以 TabBar 或折叠面板实现导航；各 Tab/区块对应列表与搜索。 |
| 顶部状态栏（模型切换、通知中心、积分显示） | 顶部自定义栏或固定组件；模型选择、通知列表、积分由接口拉取。 |

### 2.7 会员与订阅

| 功能点 | 实现要点 |
|--------|----------|
| 订阅状态与有效期、套餐对比、套餐选择与订阅 | 与 Web 用户端一致；下单后调起微信支付（后端下单并返回支付参数，小程序 `wx.requestPayment`）。 |
| 个人版/团队版，free/pro/max | 套餐展示与选择；后端配置驱动。 |

---

## 3. 与后端及微信的对接

- **鉴权**：登录后 Token 存本地；请求头携带；后端可校验微信 openid/unionid 与手机号。
- **微信支付**：后端生成预支付参数；小程序调 `wx.requestPayment`；支付结果由后端回调确认并更新订单与订阅。
- **文件上传**：小程序上传至自研后端（或经后端拿到临时上传 URL）；类型与大小限制与功能清单一致，后端统一校验。
- **流式/实时**：若小程序不支持 SSE，可采用短轮询或由后端聚合后一次性返回，以保障「步骤展示」「思考过程」等体验。
