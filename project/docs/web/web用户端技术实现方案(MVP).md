# Web 用户端技术实现方案（MVP）

**文档类型：** 端侧技术实现  
**适用范围：** Medagil Web 用户端  
**关联文档：** [总览技术实现方案(MVP)](../技术实现方案(MVP).md) · [Web 用户端功能清单(MVP)](web用户端功能清单(MVP).md)

---

## 1. 技术栈（已确定）

| 类别 | 技术 | 用途 |
|------|------|------|
| 框架 | Next.js 14+ | 应用框架、SSR/SSG、API Routes（BFF 或代理）。 |
| 语言 | TypeScript | 类型安全。 |
| UI 组件 | Radix UI | 无障碍、可定制组件（对话框、下拉、标签页等）。 |
| 样式 | Tailwind CSS | 原子化样式、响应式。 |
| 状态管理 | Zustand | 全局/客户端状态。 |
| 服务端状态 | React Query | 服务端数据拉取、缓存、同步。 |

与**管理端**共用同一套前端技术栈，通过路由与权限区分（用户端为默认/主站，管理端为独立路由或子域）。

---

## 2. 与功能清单的对应实现

以下按 [Web 用户端功能清单(MVP)](web用户端功能清单(MVP).md) 的 7 大模块，说明各模块在前端的技术实现要点。

### 2.1 个人中心与设置

| 功能点 | 实现要点 |
|--------|----------|
| 个人资料（头像、邮箱、当前计划） | 用户信息接口 + 展示组件；头像上传走对象存储接口。 |
| 升级计划 / 订阅页 | 路由跳转订阅页；套餐与价格来自后端；与会员与订阅模块联动。 |
| 积分获取（分享等） | 调用积分规则/活动接口；分享落地页与参数由后端提供。 |
| 个性化设置、退出登录 | 设置表单持久化到用户偏好接口；退出清除本地会话并调登出 API。 |
| 创建技能、定时任务、外观设置、获取帮助 | 对应后端能力；技能/定时任务为 CRUD + 列表；主题与反馈表单。 |
| 微信授权登录、手机号登录 | 由后端提供授权 URL 或手机号验证码接口；前端完成跳转与回调或表单提交。 |

### 2.2 搜索

| 功能点 | 实现要点 |
|--------|----------|
| 列表、全文搜索 | 搜索 API（关键词 + 筛选）；结果列表组件；防抖与分页。 |
| 历史对话搜索 | 对话/任务列表接口支持关键词过滤；与「侧边栏 - 搜索」共用数据源。 |

### 2.3 项目管理

| 功能点 | 实现要点 |
|--------|----------|
| 创建/查看/多级分类 | 树形结构展示；项目 CRUD 接口；拖拽排序或层级编辑（按需）。 |
| 项目编辑（新增、编辑、指令） | 表单 + 项目详情接口；全局指令为文本字段存储与回显。 |

### 2.4 成果库

| 功能点 | 实现要点 |
|--------|----------|
| 创建/查看/归档/收藏 | 成果库 CRUD 与状态接口；列表 + 卡片/列表视图切换。 |
| 列表与搜索（按名称/状态筛选） | 筛选参数与搜索关键词请求同一列表 API；分页。 |

### 2.5 任务对话

| 功能点 | 实现要点 |
|--------|----------|
| 文档支持 | Word、Excel、PPT、PDF、TXT、Markdown 上传；前端上传组件 + 后端存储与解析。 |
| 新建任务 - 文本输入 | 主输入框；提交后创建任务并可选直连 Dify 或经后端转发。 |
| 新建任务 - 附件上传 | 「+」入口上传文件/图片/链接；与后端上传接口对接。 |
| 新建任务 - 高级任务模式、语音输入 | 高级模式为表单或步骤引导；语音为录音 + 语音识别接口（后端或第三方）。 |
| 任务执行 - 步骤展示、思考过程 | 流式数据展示；与 Dify 流式 API 或后端 SSE/WebSocket 对接。 |
| 结果交互 - 内容展示 | Markdown 渲染、图表（如 ECharts）、代码高亮组件。 |
| 结果交互 - 附件下载、分享、评分反馈 | 下载链接与分享链接由后端返回；评分为简单表单提交评分 API。 |

### 2.6 导航与组织

| 功能点 | 实现要点 |
|--------|----------|
| 侧边栏 - 搜索、库、项目、所有任务、界面切换 | 侧边栏布局组件；各区块对应列表/树形数据；收起/展开状态（Zustand 或 URL）。 |
| 顶部状态栏 - 模型切换、通知中心、积分显示 | 模型列表接口；通知列表与已读状态；积分由用户信息或独立接口拉取。 |

### 2.7 会员与订阅

| 功能点 | 实现要点 |
|--------|----------|
| 订阅状态与有效期、套餐对比、套餐选择与订阅 | 订阅状态接口；套餐与权益展示页；下单调起微信支付（后端返回支付参数）。 |
| 个人版/团队版、free/pro/max | 套餐类型与名称由后端配置；前端仅展示与选择。 |

## 3. 与后端及 Dify 的对接

- **鉴权**：登录后 Token 写入 Cookie 或 Storage；请求头携带，由 API 网关或后端校验。
- **任务与流式输出**：任务创建与状态由自研后端管理；流式内容可前端直连 Dify（需后端下发 Dify 访问配置或代理）或经后端转发 SSE。
- **文件上传**：统一走自研后端上传接口，返回文件标识或 URL；解析与向量化由后端/知识库侧完成。
