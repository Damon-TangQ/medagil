## 1. 个人中心与设置

- **个人资料**：查看基本信息（头像、邮箱、当前计划）
- **升级计划**：进入订阅页面，升级至更高权限版本
- **积分获取**：通过「与好友分享」等活动获取额外积分
- **个性化设置**：设置偏好、职业背景或常用习惯，让 Medagil 更了解你；设置与偏好、退出登录
- **创建技能**：自定义技能
- **分享小程序**
- **定时任务**
- **微信授权登录、手机号码登录**
- **外观设置**
- **获取帮助**：问题反馈、在线留言

---

## 2. 搜索

- 列表、全文搜索
- 历史对话搜索

---

## 3. 项目管理

- 创建/查看/多级分类
- 项目编辑：新增、编辑、指令

## 4. 成果库

- 创建/查看/归档项目/收藏
- 列表与搜索（按名称/状态筛选）

---

## 5. 任务对话

- **文档支持**：Word、Excel、PPT、PDF、TXT、Markdown 上传
- **新建任务 - 文本输入**：在主输入框输入自然语言指令
- **新建任务 - 附件上传**：支持点击「+」图标上传文件、图片或提供链接
- **新建任务 - 高级任务模式**：定时任务、电子表格
- **新建任务 - 语音输入**：支持通过麦克风图标进行语音指令输入
- **任务执行 - 步骤展示**：实时展示 AI 执行任务的具体步骤（如：搜索、创建文件等）
- **任务执行 - 思考过程**：展示 AI 的逻辑分析和中间产物
- **结果交互 - 内容展示**：渲染生成的内容（Markdown、图表、代码预览等）
- **结果交互 - 附件下载**：提供生成文件的下载入口
- **结果交互 - 推荐追问**：根据结果自动生成后续可能的交互建议
- **结果交互 - 分享功能**：支持将任务结果通过链接分享给他人
- **结果交互 - 评分反馈**：对任务结果进行满意度评价

---

## 6. 导航与组织

- **侧边栏 - 搜索**：快速查找历史任务，支持关键词检索
- **侧边栏 - 库 (Library)**：存放已完成的任务或重要产物
- **侧边栏 - 项目 (Projects)**：支持创建文件夹归类任务，可为项目设置全局指令
- **侧边栏 - 所有任务**：按时间线展示所有历史对话，支持重命名和删除
- **侧边栏 - 界面切换**：侧边栏收起/展开切换
- **顶部状态栏 - 模型切换**：选择不同的 Manus 模型版本（如 Manus 1.6 Lite）
- **顶部状态栏 - 通知中心**：查看系统消息、任务完成提醒或更新通知
- **顶部状态栏 - 积分显示**：实时展示当前账户剩余积分

## 7. 会员与订阅

- 套餐名：free、pro、max
