# 项目概况（MVP）

**文档类型：** 需求文档
**创建日期：** 2026年2月8日
**版本：** v1.0
**适用范围：** Medagil AI 医学科研写作AI智能体平台

| 项目信息     | 内容                                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **项目名称** | Medagil AI 医学科研写作智能体平台                                                                                                            |
| **项目愿景** | 打造覆盖医学科研全流程的 AI 智能体平台，助力医学科研人员高效完成论文写作、基金申请、课题设计等工作                                           |
| **MVP 周期** | 4–6 个月                                                                                                                                     |
| **核心目标** | MVP 阶段验证 AI 智能体在论著写作、基金申请、毕业课题、科研工具四大场景的实用价值；后续阶段逐步完善各场景智能体并扩展至科普写作等完整科研场景 |
| **目标用户** | 临床医生、住院/主治医师、医学院硕博研究生、科研人员                                                                                          |
| **主要交付** | Web 用户端、小程序用户端、Web 管理端、9 个科研智能体                                                                                         |
| **技术方案** | Dify 云服务 + 自研后端 + 微信支付                                                                                                            |
