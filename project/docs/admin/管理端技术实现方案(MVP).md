# 管理端技术实现方案（MVP）

**文档类型：** 端侧技术实现
**适用范围：** Medagil Web 管理端
**关联文档：** [总览技术实现方案(MVP)](<../技术实现方案(MVP).md>) · [管理端功能清单(MVP)](<管理端功能清单(MVP).md>)

---

## 1. 技术栈（已确定）

与 **Web 用户端** 共用同一套前端技术栈，通过**路由与权限**区分管理端（如 `/admin` 或独立子域）。

| 类别       | 技术         | 用途                               |
| ---------- | ------------ | ---------------------------------- |
| 框架       | Next.js 14+  | 应用框架、SSR/SSG、API Routes。    |
| 语言       | TypeScript   | 类型安全。                         |
| UI 组件    | Radix UI     | 对话框、下拉、表格、标签页等。     |
| 样式       | Tailwind CSS | 原子化样式、响应式、管理端主题。   |
| 状态管理   | Zustand      | 全局状态、侧边栏/权限等。          |
| 服务端状态 | React Query  | 列表、详情、统计接口的缓存与同步。 |

**权限与路由**：管理端所有路由受 RBAC 控制；角色与权限数据来自后端「系统设置」模块；未授权访问重定向至登录或 403。

## 2. 与功能清单的对应实现

以下按 [管理端功能清单(MVP)](<管理端功能清单(MVP).md>) 的 9 大模块，说明各模块在前端的技术实现要点。

### 2.1 数据看板 (Dashboard)

| 功能点                                                        | 实现要点                                                |
| ------------------------------------------------------------- | ------------------------------------------------------- |
| 关键指标统计（总用户、日/周/月新增、DAU/MAU、总收入、订阅数） | 看板汇总 API；数字卡片与趋势对比。                      |
| 图表可视化（用户增长、收入、任务成功率等）                    | 图表组件（如 ECharts / Recharts）；按时间维度聚合接口。 |
| 系统状态监控（模型 API、数据库等）                            | 健康检查或状态接口；状态卡片/徽章展示。                 |
| 数据导出（Excel/PDF）                                         | 导出由后端生成或前端用表格/图表库导出；按钮触发并下载。 |

### 2.2 用户管理 (User Management)

| 功能点                                                       | 实现要点                                        |
| ------------------------------------------------------------ | ----------------------------------------------- |
| 用户列表与检索（ID、昵称、邮箱、手机、注册时间、订阅计划等） | 表格 + 筛选栏；服务端分页与排序。               |
| 用户详情（基本资料、登录历史、任务记录、订阅、积分）         | 详情抽屉/页面；多 Tab 对应不同子接口。          |
| 用户操作（禁用/解禁、改积分、重置密码、变更订阅）            | 操作按钮调后端接口；二次确认与成功提示。        |
| 批量操作（导出、批量通知）                                   | 多选 + 批量操作 API。                           |
| 用户标签管理                                                 | 标签 CRUD 与用户-标签关联接口；标签选择器组件。 |

### 2.3 任务与对话管理 (Task & Dialogue Management)

| 功能点                                           | 实现要点                                                   |
| ------------------------------------------------ | ---------------------------------------------------------- |
| 任务流水查询（指令、步骤、思考过程、结果、反馈） | 任务列表 API（筛选、分页）；详情展开或侧边栏展示完整内容。 |
| 异常任务监控（失败、超时）                       | 筛选条件 + 状态/耗时字段；高亮或标记异常行。               |
| 内容审查、任务统计分析                           | 审查为标记/备注接口；统计为图表数据接口。                  |
| 用户反馈管理                                     | 反馈列表与评分展示；状态或分类筛选。                       |

### 2.4 项目与成果管理 (Project & Achievement Management)

| 功能点                                         | 实现要点                                     |
| ---------------------------------------------- | -------------------------------------------- |
| 项目数据统计、成果库监控（存储、文件类型分布） | 统计接口 + 图表或表格。                      |
| 内容审核、存储管理                             | 审核状态与操作接口；存储用量与文件列表接口。 |

### 2.5 会员与订单管理 (Subscription & Order Management)

| 功能点                                             | 实现要点                                             |
| -------------------------------------------------- | ---------------------------------------------------- |
| 订阅套餐配置（Free/Pro/Max、定价、权益、积分额度） | 套餐 CRUD 表单与列表；与「会员与订阅」业务模型一致。 |
| 订单流水（订单号、用户、套餐、支付状态）           | 订单列表与筛选；详情弹窗或页面。                     |
| 财务与退款、收入分析（MRR、LTV、转化率）           | 退款操作接口；收入与转化率为统计接口 + 图表。        |
| 活动促销（优惠券、限时折扣）                       | 活动 CRUD；与订单或套餐关联配置。                    |

### 2.6 积分管理 (Credits Management)

| 功能点                        | 实现要点                                   |
| ----------------------------- | ------------------------------------------ |
| 积分规则配置（获取/消耗规则） | 规则配置表单与列表。                       |
| 积分流水、积分调整、积分统计  | 流水列表与筛选；单用户调整表单；统计图表。 |

### 2.7 知识库管理 (Knowledge Base Management)

| 功能点                                        | 实现要点                                                              |
| --------------------------------------------- | --------------------------------------------------------------------- |
| 知识源管理（PDF、Word、TXT、Markdown 等上传） | 上传组件；后端解析与写入 Zilliz 由知识库服务完成。                    |
| 内容创建与编辑（富文本）                      | 富文本编辑器（如 TipTap/Lexical）；保存至知识库元数据与版本。         |
| 分类与标签、版本控制、访问权限                | 树形分类与标签 CRUD；版本历史列表与回溯操作；权限与订阅等级关联配置。 |
| 使用情况分析（浏览量、搜索词、反馈）          | 统计接口 + 表格或图表。                                               |

### 2.8 内容与运营管理 (Content & Operations Management)

| 功能点                             | 实现要点                                               |
| ---------------------------------- | ------------------------------------------------------ |
| 技能管理（审核、公共技能库）       | 技能列表与审核状态操作；推荐/上下架。                  |
| 通知与公告发布                     | 富文本编辑与推送目标选择；定时或立即发送接口。         |
| 用户反馈处理（获取帮助提交的反馈） | 反馈列表、分类、指派、状态流转。                       |
| 模型与配置管理、定时任务管理       | 模型列表与权限配置；用户定时任务列表与暂停/恢复/删除。 |

### 2.9 系统设置 (System Settings)

| 功能点                       | 实现要点                                           |
| ---------------------------- | -------------------------------------------------- |
| 管理员与角色权限 (RBAC)      | 角色 CRUD；权限树勾选与保存；与前端路由/菜单联动。 |
| 系统日志                     | 操作日志列表与筛选、导出。                         |
| 参数配置（API 密钥、存储等） | 配置项表单；敏感项脱敏与更新接口。                 |
| 登录方式管理、外观与品牌设置 | 登录方式开关；Logo、主题色等上传与配置。           |

---

## 3. 与后端的对接约定

- **鉴权**：管理端登录与 Token 与用户端隔离（或同一登录体系 + 角色区分）；所有管理端 API 需校验管理员角色与模块权限。
- **数据范围**：列表与统计均为全平台数据，由后端按角色做数据权限过滤（若后续做多租户再扩展）。
- **操作审计**：关键写操作由后端记入「系统日志」，前端无需单独上报。
