# 开发排期（MVP）

**文档类型：** 计划排期文档  
**创建日期：** 2026年2月8日  
**版本：** v1.0  
**适用范围：** Medagil AI 医学科研写作AI智能体平台

## 总览

| 阶段 | 时间 | 核心交付概要 | 智能体交付 |
|------|------|--------------|------------|
| MVP-A | 第 1–2 个月 | 需求演示、基础设施、核心业务、里程碑 M1 | — |
| MVP-B | 第 3–4 个月 | 智能体能力扩展、商业化系统、里程碑 M2 | 3/9（临床论著、文献分析、智能选刊） |
| MVP-C | 第 5–6 个月 | 知识库系统、高级功能、里程碑 M3 | 6/9（+基础论著、面上基金、博士临床课题） |
| MVP-D | 第 7 个月 | 性能优化、用户体验优化 | 9/9（+综述助手、博士基础课题、重点/专项基金） |
| 优化期-B | 第 8 个月 | 全面测试、上线准备、里程碑 M4 | 智能体优化与最终验收 |

---

## MVP-A：第 1–2 个月

### 核心交付

**需求演示**

- 前端所有功能的页面 Demo 演示

**基础设施层（第 1 个月）**

- 用户认证系统（微信/手机号登录）
- 数据库设计与部署
- API 网关与文件存储系统
- 前端框架搭建（Web + 小程序 + 管理端）

**核心业务功能（第 2 个月）**

- 任务对话系统（文本输入/响应/步骤展示）
- 项目管理（创建/编辑/分类）
- 导航与组织（侧边栏/顶部状态栏）
- 个人中心（基础信息/设置）
- 管理端：用户管理/任务查询/数据看板

### 里程碑 M1

- ✓ 用户可完成注册登录并创建基础任务
- ✓ 管理员可查看用户和任务数据

### 智能体交付

本阶段无智能体交付，以平台基础能力为主。

---

## MVP-B：第 3–4 个月

### 核心交付

**智能体能力扩展（第 3 个月）**

- 任务对话增强（附件上传/语音输入/分享/评分）
- 成果库系统（创建/归档/收藏/搜索）
- 全文搜索与历史对话搜索
- 管理端：任务详细管理/异常监控/内容审查

**商业化系统（第 4 个月）**

- 积分系统（实时显示/消耗/获取）
- 会员与订阅（套餐对比/Free/Pro/Max）
- 微信支付集成（扫码支付）
- 通知中心（系统消息/任务提醒）
- 管理端：订单管理/财务分析/积分管理

### 里程碑 M2

- ✓ 付费流程完整可用
- ✓ 6 个智能体能力上线

### 智能体交付

**论著写作类**

- **临床论著助手** — 快速成型标准 IMRAD 结构初稿（研究信息采集/框架生成/初稿生成/文档输出）

**科研工具类**

- **文献分析助手** — 文献快速阅读与分析（单篇总结/多篇对比/核心观点提取）
- **智能选刊助手** — 期刊匹配与投稿建议（期刊推荐/影响因子展示/投稿要求汇总）

**智能体完成度**：3/9  
**技术重点**：PDF 解析、IMRAD 框架、期刊数据库

---

## MVP-C：第 5–6 个月

### 核心交付

**知识库系统（第 5 个月）**

- 知识库浏览（分类导航/文章查看/搜索）
- 知识库与任务集成
- 管理端：知识库管理（上传/编辑/分类/标签/版本控制/权限控制）

**高级功能完善（第 6 个月）**

- 定时任务（创建/调度/执行通知）
- 技能管理（创建自定义技能/技能库）
- 外观设置（主题切换/个性化）
- 获取帮助（问题反馈/在线留言）
- 管理端：运营管理（技能审核/通知发布/反馈处理/模型配置）

### 里程碑 M3

- ✓ 10 个 MVP 智能体全部上线
- ✓ 知识库系统正常运行
- ✓ 定时任务可按时执行

### 智能体交付

**论著写作类**

- **基础论著助手** — 辅助基础医学研究论文撰写（实验方法描述/结果图表化建议/研究故事线构建）

**基金申请类**

- **国自然面上基金助手** — 面上项目申请书撰写辅助（面上项目特点适配/研究基础展示/团队优势描述）

**毕业课题类**

- **博士临床研究课题助手** — 博士生临床研究课题设计（临床课题设计/研究方案规划/伦理考量）

**智能体完成度**：6/9  
**技术重点**：实验类型识别、图表推荐、基金模板

---

## MVP-D：第 7 个月

### 核心交付

**性能优化**

- 数据库优化（索引/慢查询/连接池调优）
- 接口性能优化（响应时间/缓存策略/CDN）
- 前端性能优化（代码分割/懒加载/首屏优化）
- 并发能力提升（任务队列/负载均衡/限流熔断）
- 稳定性提升（异常处理/日志/监控告警）

**用户体验优化**

- 交互细节优化（加载状态/错误提示/操作反馈）
- 响应式适配完善
- 小程序性能优化
- 管理端数据看板优化

**目标**

- ✓ API 响应时间 &lt; 500ms
- ✓ 页面加载时间 &lt; 3s
- ✓ 系统可用性 &gt; 95%

### 智能体交付

**论著写作类**

- **综述/范围综述助手** — 系统性文献综述写作辅助（文献检索策略生成/文献筛选辅助/数据提取结构化）

**毕业课题类**

- **博士基础研究课题助手** — 博士生基础研究选题和开题（前沿课题推荐/开题报告生成/创新点提炼）

**基金申请类**

- **国自然重点/专项基金助手** — 重点/专项项目申请策略（重点项目策略/大项目组织/多团队协作）

**智能体完成度**：9/9 ✓  
**技术重点**：PRISMA 流程、前沿文献追踪、协作框架

---

## 优化期-B：第 8 个月

### 核心交付

**全面测试**

- 功能测试（完整回归/跨端一致性/智能体验证）
- 性能测试（压力测试/稳定性测试/兼容性测试）
- 安全测试（渗透测试/数据安全/支付安全）
- 用户验收测试（内部测试/Beta 测试/问题修复）

**上线准备**

- 生产环境部署
- 数据备份策略与灾难恢复预案
- 运维文档编写
- 用户使用手册与 FAQ
- 客服培训
- 用户协议与隐私政策
- 内容审核机制
- 数据合规检查

### 里程碑 M4

- ✓ 所有功能通过测试
- ✓ 性能指标达标
- ✓ 安全测试通过
- ✓ 正式上线发布 🚀

### 智能体交付

**智能体优化**

- 所有智能体响应速度优化
- 智能体错误处理完善
- 智能体能力稳定性提升

**优化重点**

- 降低 API 调用延迟
- 优化模型推理速度
- 完善降级策略

**智能体最终验收**

- 9 个智能体全面测试
- 智能体协同工作验证
- 智能体性能达标确认
- 智能体安全性审核
- 用户场景全覆盖测试

**交付标准**

- ✓ 所有智能体稳定可用
- ✓ 响应准确率 &gt; 80%
- ✓ 用户满意度 &gt; 4/5
- ✓ 医学专业性验证通过
